# AZhanabekova-NVS-TA

Creative Producer test assignment for Nomad Venture Studio by Alua Zhanabekova.

A static, multi-page website. Open `index.html` to start. No installation or build step is required.

| Page | Content |
| --- | --- |
| [Overview](index.html) | Assignment requirements and CV |
| [Task 1](task-1.html) | 7ART creative analysis and iteration plan |
| [Task 2](task-2.html) | Analysis of three stock videos |
| [Task 3](task-3.html) | Creative research, benchmarking and hypotheses |
| [Task 4](task-4.html) | Three 1080×1350 statics and a six-frame storyboard |
| [References](references.html) | Design reference and research links |

## Local preview

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Files

- `style.css`, `fonts.css`, `app.js`: shared styles, local fonts and interactions.
- `media/`: supplied videos and extracted frames.
- `task3/`: competitor reference screenshots.
- `task4/`: final creative assets, storyboard and downloadable materials.
- `documents/`: CV.

The pages and assets use relative URLs and can be served by any static web host.
